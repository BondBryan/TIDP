Project volumes / buildings

Optional. Tick when the project is split into several buildings or volumes. Items marked "per volume" are duplicated once per volume; otherwise the volume code stays ZZ.

Programme: stage delivery dates

Enter the planned issue date for each RIBA stage. It is applied to every deliverable that is first issued at that stage (the "YYYY-MM-DD" placeholder in the Library). Later stages stay "Ongoing". Leave blank to keep the placeholder for the team to fill in Excel.

Deliverables

Review & export

Check the totals, save the project file to the project server (so the TIDP can be reopened and revised), then export.

1. Save the project file

A small .json file with the project details and selections. Save it in the project's TIDP folder next to the Excel. Reopen it on step 1 to issue the next revision.

2. Export the TIDP (Excel)

Macro-free workbook: Cover, one sheet per document type, and a flat Data sheet linked by formula to the content sheets so edits made in Excel flow through to the raw list.


3. Internal resourcing note

For the Project Lead only. Lists Outsourcing Partner items, internal team items and items needing scope confirmation, with the Library comments. Produced as a Word document.
